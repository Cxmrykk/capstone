# Log 017: Infrastructure Pivot 2 - Migrating to UTS CETUS Supercomputer

**Date:** September 3, 2026

**Context:**
The project requires a stable, zero-budget infrastructure solution with sufficient VRAM (>24GB) to train 4B parameter models on Text-to-Cypher tasks. 
- **Attempt 1:** Google Colab (T4 Free Tier - 16GB). Failed due to severe Out-Of-Memory (OOM) exceptions when processing the required 2048 token context windows.
- **Attempt 2:** Google Cloud Platform (GCP). Attempted to provision an L4 (24GB) using the $300 free trial credits, but was hard-locked by automated anti-abuse quotas that restrict new/free accounts from accessing GPUs without upfront payment history.

**Modifications & Rationale:**
- **Discovery:** Discovered the newly launched UTS "CETUS" HPC cluster, which features compute nodes equipped with dual NVIDIA RTX 6000 Pro GPUs (96GB VRAM each). 
- **Action:** Attempted to apply via the official IT portal, but discovered the ServiceConnect forms were broken/unpublished following the system migration from the old iHPC.
- **Escalation:** Bypassed the broken portal and escalated the request directly to the eResearch engineering team via email (`eResearch-IT@uts.edu.au`), CCing my academic supervisor to establish project legitimacy.
- **Impact:** Access to 96GB of VRAM will entirely eliminate OOM constraints. It will allow the pipeline to run larger batch sizes without relying on aggressive gradient accumulation, drastically reducing training time.
- **Engineering Changes:** The execution model must now shift from interactive notebook/terminal sessions to batch processing. I am currently adapting the execution flow to utilize `PBS Pro` job submission scripts.
