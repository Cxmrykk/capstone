# 010 - Replace hf with huggingface-cli in Download Script

## Context
In `history/009.md`, a runtime regex patch using `sed` was temporarily added to `google-colab.ipynb` to modify `download_data.sh`. This was done because the alias `hf` for the Hugging Face CLI is not consistently available across all Colab environments, leading to `command not found` errors.

## Modifications
- **download_data.sh**: 
  - Permanently replaced all instances of `hf download` with `huggingface-cli download` to ensure robustness and eliminate cross-platform aliasing dependencies.
- **google-colab.ipynb**: 
  - Removed the brittle `!sed -i ...` regex patching from the "Download Dataset & Models" cell. The script is now invoked directly via `!bash download_data.sh`.
