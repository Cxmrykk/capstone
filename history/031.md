# Log 031: Notebooks Assembled from Chunk Directories

**Context:**
The four notebooks (training/final-eval x Colab/Kaggle) are large single JSON files with heavily
duplicated helpers (step runner, ntfy, Hub upload). Edits had to be repeated by hand across copies,
which already caused drift (history/029.md, history/030.md list edits still pending for the Colab
notebooks). Notebooks are now assembled from per-notebook chunk directories by a build script.

**Modifications:**
- **Added `notebooks/build.py`:** builds `notebooks/<name>.ipynb` from `notebooks/<name>/`.
  - `NN-name.py` / `.md` / `.raw` become code / markdown / raw cells, ordered by numeric prefix.
    Duplicate prefixes and unknown files are errors. An empty directory never overwrites a notebook.
  - `# %include _shared/<file>` (code) and `<!-- %include ... -->` (markdown) inline shared snippets
    from `notebooks/_shared/`, keeping indentation. Cycles and paths outside `notebooks/` are rejected.
  - Deterministic output (no outputs, `execution_count: null`). `--check` exits 1 on stale notebooks,
    `--list` shows chunk order, and `--validate` runs nbformat validation.
- **Added `notebooks/<name>/notebook.json`** for each notebook, holding notebook-level metadata
  (kernelspec, Kaggle accelerator/internet flags) copied from the existing `.ipynb`.
- **`.gitattributes`:** `notebooks/*.ipynb` marked `linguist-generated`.

**Logs & Metrics:**
- `training-kaggle` (9 chunks) and `final-eval-kaggle` (14 chunks): `build.py --check` reports ok,
  so the output is byte-identical to the previous notebooks.
- Pending: chunk `training-colab` and `final-eval-colab`; move duplicated helpers into `_shared/`.
