# Log 003: Formatting the Chat Template Output

**Context:** 
The user requested better formatting for the extracted Qwen Chat Template, as wrapping it in JSON resulted in an unreadable, single-line string with escaped newlines.

**Changes & Reasons:**
- **Modified `data.py`:** Refactored the helper function from `save_config_as_json` to a generic `save_file`. 
- **Why:** When `is_json=False`, the script now writes the file out as raw text (specifically as `.jinja`) rather than wrapping it in a JSON dictionary. This stops python's `json` module from escaping the newlines (`\n`) and preserves the original, highly readable multi-line template structure.
