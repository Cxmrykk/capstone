# 011 - Revert huggingface-cli to hf due to upstream deprecation

## Context
In `history/010.md`, the `download_data.sh` script was modified to use `huggingface-cli download` instead of `hf download`. However, newer versions of `huggingface_hub` (>=1.28.0) strictly enforce the deprecation of `huggingface-cli` and abort execution, which crashed the Colab pipeline during the data download phase.

## Modifications
- **download_data.sh**: 
  - Reverted the download commands from `huggingface-cli download ...` back to the modern `hf download ...` syntax.
- **google-colab.ipynb**: 
  - Maintained the clean execution call (`!bash download_data.sh`) established in the previous update, ensuring no regex parsing (`sed`) was needed.
