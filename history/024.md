# Log 024: Kaggle Notebook (Single-T4 Pin, Session-Budgeted Training)

**Context:**
Kaggle's free GPU tier (phone-verified account, T4 x2 or P100, ~12 h sessions, weekly GPU
quota) is added alongside Colab. `google-colab.ipynb` does not run there: `google.colab.userdata`
is imported outside the try block (cell 2 crashes), `/content` does not exist (cell 3's
`cwd="/content"` fails), and with two visible T4s HF `Trainer` wraps the model in
`nn.DataParallel`. That is fragile with 4-bit bitsandbytes and would double the effective batch
size (16 -> 32) without changing the config fingerprint, so a Colab run resumed on Kaggle
would silently switch regimes.

**Modifications:**
- **Added `kaggle.ipynb`:** Kaggle counterpart of the Colab notebook, same steps, logging,
  Hub mirroring and ntfy alerts.
  - Fails fast on: non-Kaggle runtime, no GPU, P100 (Pascal), no internet, missing `HF_TOKEN`
    (read via `kaggle_secrets.UserSecretsClient`). Missing token is fatal because scratch storage
    is wiped at session end, so training without Hub sync would lose all progress.
  - Sets `CUDA_VISIBLE_DEVICES=0` before any subprocess runs (single T4, same maths as Colab).
  - Repo, models and artifacts go to `SCRATCH_DIR` (`/kaggle/temp`, fallback `/tmp`); logs and
    small results go to `/kaggle/working/text2cypher-logs/...`, saved as the version's output.
    Free space is reported; under 40 GB triggers a warning.
  - Training limit = min(`TIME_LIMIT_MINUTES`, 720 - elapsed - `RESERVE_MINUTES`). The reserve
    covers model load and tokenization (before `WallClockLimitCallback` starts), checkpoint
    upload, and predict/eval. `time_limit_minutes` is excluded from the fingerprint, so varying
    it per session does not block resume.
  - A time-limit pause (exit 4) or insufficient session time sets `HALTED`; later cells skip
    instead of raising, so a committed (Batch) version completes and its output is saved.
  - Session IDs carry a `-kaggle` suffix so Hub `logs/` and `results/` show the platform.
- **`src/paths.py`:** `is_kaggle()` (`KAGGLE_KERNEL_RUN_TYPE` or `/kaggle/working`) and
  `platform_name()`. Path resolution unchanged.
- **`src/env.py`:** doctor reports the platform and Kaggle run type, visible GPU count and
  `CUDA_VISIBLE_DEVICES`; warns on >1 visible GPU (DataParallel) and on pre-Turing GPUs;
  platform-specific no-GPU and no-Hub messages.
- **Unchanged:** `google-colab.ipynb`, `scripts/colab_bootstrap.sh` (platform-neutral, reused),
  all training/inference/evaluation code and configs.
