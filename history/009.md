# 009 - Integrated Data Download into Colab Pipeline

## Context
Running `app.py data preview` or `app.py train` natively out of the box in the `google-colab.ipynb` file triggered a `FileNotFoundError`. The toolkit correctly identified that the `text2cypher-2024v1` dataset and model weights were missing from the local environment and explicitly instructed the user to execute `./download_data.sh`.

## Modifications
- **google-colab.ipynb**: 
  - Inserted a new dedicated Markdown and Code block at Step 2 (`Download Dataset & Models`).
  - Added an inline `sed` command to patch `download_data.sh` prior to execution (`sed -i 's/hf download/huggingface-cli download/g'`). This preemptively guards against `hf` not being automatically aliased to `huggingface-cli` within standard Google Colab instances.
  - Re-numbered the subsequent pipeline steps (Diagnostics, Fine-Tuning, Inference, Evaluation, Exporting) to maintain sequential continuity.
