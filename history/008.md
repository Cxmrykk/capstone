# 008 - Default Colab Notebook Model Swapped to gemma-4-E2B

## Context
The default configuration for the Google Colab testing notebook (`google-colab.ipynb`) has been updated to use the `gemma-4-E2B` model configuration rather than `qwen3.5-2b`. This ensures that the primary execution paths demonstrated to users accurately reflect the chosen lightweight Google model for edge and hardware-constrained testing.

## Modifications
- **google-colab.ipynb**: 
  - Updated `app.py data preview`, `app.py train`, `app.py predict`, and `app.py export merge` commands to target `--config configs/gemma-4-e2b.yaml`.
  - Updated adapter and merged model directories to align with the `run_name` specified in the Gemma 2B configuration (`artifacts/runs/gemma-4-e2b-enhanced/final` and `artifacts/merged/gemma-4-e2b-enhanced`).
  - Swapped prediction output paths from `qwen3.5-2b-test.jsonl` to `gemma-4-e2b-test.jsonl`.
  - Adjusted surrounding markdown to reflect the default model swap.
